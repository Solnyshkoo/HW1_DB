# Петрова Ксения Эдуардовна_HW_01
Внутри папки HW1 лежит ноутбук Петрова Ксения Эдуардовна_HW_01.ipynb с выполненными ячейками и результатом их работы.
В scripts лежат чисто запросы, которые были использованы. В scripts опущены подробности про нормализацию, про это сказано только в тексте работы. 

При запуске ноутбука данные считаются из папки data самостоятельно. Однако при запуске scripts, потребуется выполнить сначала создание таблиц, а потом через терминал заполнить их данными. Пример команды psql -d postgres -c "\copy raw_customers FROM 'data/customers.csv' WITH (FORMAT csv, HEADER true, DELIMITER ',');" 
Все команды отражены в комментариях
